# 💰 Super E-Wallet App

A modern **E-Wallet Web App** built with Firebase, supporting balance management, transfers, and QRIS payment integration.  
Designed to be converted into an Android APK with AdMob monetization.

---

## 🚀 Features

- 🔐 Authentication (Email & Password)
- 💰 Real-time Balance (Firebase Realtime DB)
- 🔁 Transfer between users
- 🧾 Transaction History
- 💳 QRIS Top-up (Midtrans Ready)
- 📱 Android APK (via WebView)
- 💸 AdMob Monetization Ready

---

## 🧱 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Firebase (Auth + Realtime Database)
- Payment Gateway: Midtrans (QRIS)
- Mobile: Android (WebView)
- Ads: Google AdMob
